Characters / 캐릭터 / キャラクター / 角色

One folder per model, with its textures:   characters/<name>/<model>.pmx
Formats: PMX, VRM, glTF/GLB, FBX. Non-PMX models need a humanoid skeleton (VRoid/VRM, Mixamo,
Ready Player Me, Unity/Blender/UE rigs); they are converted to MMD bones on load (no physics).

모델마다 폴더 하나 (텍스처 포함). PMX, VRM, glTF/GLB, FBX 휴머노이드 모델.
モデルごとにフォルダを一つ (テクスチャ込み)。PMX / VRM / glTF / FBX の人型モデル。
