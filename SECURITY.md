# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through [GitHub's vulnerability reporting form](https://github.com/digital8150/MMDX12/security/advisories/new).

Include the affected version, the component, the steps or a test file that reproduce the problem, and what an attacker could do with it. English, Korean, Japanese and Chinese are all fine.

MMDX12 is maintained in spare time, so a reply may take a while. Please keep the details private until a fix is released.

## Supported versions

Fixes go into the next release. Only the latest release is supported.

## What to report

- The updater and optional component downloads
- Downloading and installing shader packs and stages from the online galleries
- Crafted files that corrupt memory or write outside the expected folders when opened: models, motions, projects, archives, images and effects
- Unintended access through the local MCP control pipe
- The online gallery and leaderboard services

## What to report elsewhere

Problems in third-party libraries that are not specific to how MMDX12 uses them belong with those projects. Problems in a third-party shader pack, stage or model belong with its author.
